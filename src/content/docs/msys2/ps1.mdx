### 问题

MSYS2 是在 Windows 上使用 Bash 以及其他 POSIX 工具的兼容环境。然而，默认的 MSYS2 终端提示符如下所示：

```
user@desktop UCRT64 ~
$
```

和现代 Linux 的默认提示符大相径庭，且提示符占用了双行也很难看。

### 解决方案

打开 `/etc/bash.bashrc`，编辑其中的 `PS1` 变量，使其为：

```bash
export PS1='\[\e]0;\w\a\]\[\e[01;32m\]\u@\h\[\e[01;37m\]:\[\e[01;34m\]\W\[\e[0m\]'"${_ps1_symbol}"' '
```

就能使得 MSYS2 的默认提示符和 Linux 对齐。

### 详细解释

接下来是对此提示符作用的详细解释。

#### 1. 设置终端窗口标题

```
\[\e]0;\w\a\]
```

- `\[` 和 `\]`：标记非打印字符序列的开始和结束。它告诉 Bash 里面的内容不会占用终端的光标位置（只是控制终端行为）。
- `\e`：转义字符（Escape），相当于键盘上的 Esc 键，是几乎所有终端控制序列的起始。
- `]0;`：设置终端窗口的标题和图标名称。
- `\w`：当前工作目录的完整路径（例如 /home/user/project）。
- `\a`：标题设置完毕。

#### 2. 用户名和主机名

```
\[\e[01;32m\]\u@\h
```

- `\e[01;32m`：ANSI 颜色控制码。01 表示粗体/高亮，32 代表绿色。这会将后续文字设为亮绿色。
- `\u`：当前用户名（username）。
- `@`：字面字符 @。
- `\h`：当前主机名（hostname）。

#### 3. 冒号分隔符（白色）

- `\e[01;37m`：01 粗体，37 代表白色。将颜色切换为亮白色。
- `:`：字面字符冒号，用来分隔主机名和路径。

#### 4. 当前工作目录（蓝色）

```
\[\e[01;34m\]\W
```

- `\e[01;34m`：01 粗体，34 代表蓝色。将颜色切换为亮蓝色。
- `\W`：当前工作目录的基名（即最后一级文件夹名）。如果你在 $HOME 目录下，它会聪明地显示为 `~`。

#### 5. 重置颜色与结尾符号

```
\[\e[0m\]"${_ps1_symbol}"' '
```

- `\e[0m`：重置所有文本属性。把颜色、粗体等全部恢复为终端默认样式，防止你输入的命令也跟着变色。
- `"${_ps1_symbol}"`：这是一个 Bash 变量。因为你用了双引号，它会在你执行 export 这条命令时被展开。通常这个变量里存的是 `$` 或 `#`（root 用户是 `#`），或者是你自定义的一个符号（比如 `➜` 或 `>`）。
- `' '`：最后的一个空格，为了让光标和命令之间有个呼吸感，方便输入。
